LTL PHASE 8 SETUP

1. Upload the extracted ZIP contents to the ROOT of your existing GitHub repository, replacing matching files.
2. In Supabase Dashboard > SQL Editor, run phase-8-tests-setup.sql AFTER your Phase 7 setup.
3. Commit the GitHub changes and wait for Vercel deployment.
4. Open Exam > Test > choose Subject. Admins see Create test in that subject's Test area.
5. Set the start date/time and duration in minutes (60 = 1 hour). Add questions manually or scan a text-based PDF. Confirm every correct answer before publishing.
6. Learners see the scheduled time. They can start only at/after that time and get one attempt only. The timer auto-submits and shows final marks.

Do not remove your existing Phase 6/7 SQL tables or environment variables. Back up the repository/database before applying updates.
